# DeepSeek_BigFatFish

> Try something interesting

一个 QQ 陪伴型机器人的公开资料：**记忆框架** + **记忆海（可视化）**。

宿主是自建的桥接程序（Node），模型走 DeepSeek，QQ 侧接 OneBot 网关。
本仓库放**设计文档、参数表、可复用的核心代码**。

## 目录

```
记忆框架与记忆海/
├─ README.md            总览
├─ 01-整体架构.md        五块怎么拼起来、一条消息走完的路径
├─ 02-记忆内核.md        存什么、怎么衰减、怎么合并、怎么归档
├─ 03-检索层.md          库大了怎么按当前话题挑 6~10 条
├─ 04-记忆海.md          把记忆画成三维星海
├─ 05-部署与调参.md      接入步骤 + 灰度顺序 + 回滚
├─ 06-参数速查.md        一页纸看完所有数字
├─ code/               零依赖核心代码
└─ memory-sea/         记忆海的实现说明
```

## 上手顺序

1. 读 `01-整体架构.md`，知道有哪几层
2. 读 `02` / `03`，这是"记得住"和"挑得准"的两块
3. 想看图，读 `04`
4. 真要部署，直接跳 `05`
