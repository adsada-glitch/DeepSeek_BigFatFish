# 记忆海 · 实现说明

把「长期记忆 + 聊天记录 + 日记」画成一片可以旋转的三维星海。
一颗星是一件事，一根线是两件事的相似，颜色是类型。

纯前端 Canvas 2D，无 WebGL、无第三方运行时依赖。

## 模块分工

```
memory-sea/
├─ src/
│  ├─ memory-store.js      长期记忆状态机（active / pending / superseded / expired / stale）
│  ├─ memory-retrieve.js   检索打分（中文 bigram + IDF + 时段联想 + 预算装箱）
│  ├─ mind-sea.js          点 / 边 / 簇 / 场景
│  ├─ scene-service.mjs    胶水层
│  └─ server.mjs           零依赖 HTTP 服务（默认 4173）
├─ public/index.html       单文件渲染器
├─ data/qq.json            你的数据
└─ tools/export-qq.mjs     导出脚本
```

前三块是纯函数，可以脱离渲染单独用；`server.mjs` 只做静态文件 + 两个接口。

## 主题表外置

主题词典不写死在渲染器里，而是**随数据传进来**：

1. 导出时在 JSON 里带 `topicLabels`
2. `scene-service` 把它塞进 `cfg.topicLabels`
3. `topicLabel()` 优先查传入的表，查不到才回落内置表

这样换一套主题只改一个表，不动源码：

```js
const THEMES = [
  ['self',    '她自己', ['鲸鱼', '女仆', '体重', '可爱']],
  ['owner',   '本人',   ['主人', '带我', '答应']],
  ['sticker', '表情包', ['表情', '图片', '梗图', '斗图']],
  ['games',   '打游戏', ['上号', '开黑', '这局', '抽卡']],
  ['food',    '吃什么', ['吃', '干饭', '奶茶', '外卖', '夜宵']],
  ['tech',    '弄电脑', ['记忆', 'token', '部署', '代码', '接口']],
  ['video',   '刷视频', ['视频', '刷到', '直播']],
  ['mood',    '心情',   ['累', '烦', '开心', '难过', '想你']],

```

顺序有讲究：越具体的放越前，一句话同时命中多个主题时，先命中的赢。

## 密度调优

| 参数 | 默认 | 调整后 | 原因 |
| --- | --- | --- | --- |
| `minEdgeScore` | 0.15 | 0.26 | 线少三成，不糊成一团 |
| `maxNeighbors` | 6 | 4 | 每点最多四根线 |
| `maxPoints` | 4000 | 900 | 兜底 |
| `CAM_DEFAULT.dist` | 1200 | 1900 | 默认镜头拉远 |

## 宇宙感（纯 Canvas 2D）

| 效果 | 做法 |
| --- | --- |
| 星云 | 5 团淡径向渐变，离屏画一次 |
| 星场 | 620 颗三层深度，随镜头视差移动 |
| 星光 | 预渲染 64×64 光晕精灵，加色混合 |
| 闪烁 | 每颗独立相位（`hash(id)` 取模） |
| 漂移 | 鼠标闲置 5 秒后自转约 0.4°/秒 |

**性能关键**：光晕必须预渲染成精灵图，不能每帧给每个点重建渐变，否则几百个点就掉到 20 帧。

## 数据导出

`tools/export-qq.mjs` 把桥接的状态转成三段 JSON：

```
state/memory/memory-state.json  → longTerm
state/social-v2.json            → messages
state/diary/*.md                → diaries（去掉 markdown 标记，压成一行）
```

**只读**：只读桥接的 `state/`，只写自己的 `data/qq.json`，从不反向写。

## 接口

```
GET  /api/scene    → { points, edges, stats }
POST /api/rebuild  → 重算布局
GET  /api/health   → { ok, points }
```

前端只认这个结构，后端换语言也能复刻。

## 起服务

```bash
node tools/export-qq.mjs --root ../你的桥接目录
DATA=./data/qq.json PORT=4173 node src/server.mjs
```

浏览器打开 `http://127.0.0.1:4173`。

## 注意

- 它**只读**，删掉整个目录不会影响机器人
- 数据只在服务启动时读一次，改了 JSON 要重启
- 数据量到几千点会开始掉帧，先调 `maxPoints` 或只导最近 N 天
