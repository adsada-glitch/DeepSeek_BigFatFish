# 06 · 参数速查

一页纸，所有能调的数字。

## 记忆内核（memory-core）

| 参数 | 默认 | 本项目 | 说明 |
| --- | --- | --- | --- |
| `injectLimit` | 80 | 80 | 按权重注入时的上限（检索层接管后基本不用） |
| `archiveThreshold` | 120 | **800** | 活跃条目超过就归档 |
| `archiveBatch` | 20 | 20 | 每次归档多少条 |
| `decayMode` | linear | linear | linear / ebbinghaus |
| `decayNormal` | 0.1 | 0.1 | 每天扣分 |
| `decayLowConfidence` | 0.16 | 0.16 | 低可信条目扣得更快 |
| `stabilityBase` | 3 | 3 | 艾宾浩斯：基础强度（天） |
| `stabilityGrowth` | 1.6 | 1.6 | 艾宾浩斯：每次复习的倍数 |
| `reinforce` | 0.5 | 0.5 | 相似合并时加多少分 |
| `maxWeight` | 6.0 | 6.0 | 权重上限 |
| `similarThreshold` | 0.62 | 0.62 | 相似合并阈值 |
| `sinkThreshold` | 1.0 | 1.0 | 低于多少算沉底 |
| `sinkPerDay` | 3 | 3 | 连续多少天沉底才真的不注入 |
| `backupKeepDays` | 7 | 7 | 备份保留天数 |
| `snapshotKeep` | 10 | 10 | 快照保留份数 |

## 基础权重

| 标签命中 | 分数 |
| --- | --- |
| 约定 / 承诺 / 情绪 / 身份 / 边界 | 3.0 |
| 偏好 / 作息 | 2.5 |
| 梗 / 表情 / 群友 | 1.6 |
| 钱 / 余额 / 操作 / 教训 / 功能 | 1.3 |
| 其它 | 1.8 |

## 置信度折扣

| confidence | 折扣 |
| --- | --- |
| < 0.5 | × 0.45 |
| < 0.75 | × 0.7 |

来源默认值：本人 1.0 / 推断 0.6 / 旁人 0.45。

## 检索层（pick）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `maxInject` | 8 | 最多挑几条 |
| `budgetChars` | 600 | 记忆段字数预算（≈400 token） |
| `minPick` | 3 | 少于这个数就回退按权重 |
| `fallbackBelow` | 12 | 库小于这个数直接按权重全给 |
| `queryChars` | 240 | query 最多取多少字 |
| `coreTopics` | profile, owner-profile | 核心主题保底 |

## 检索打分

```
score = 2.2 × IDF重叠 + 1.2 × 主题命中 + 1.0 × 新鲜度 + 类型权重
```

| 项 | 值 |
| --- | --- |
| 新鲜度半衰 | 45 天 |
| 类型权重 | fact 0.3 / promise 0.25 / 其它 0.15 |
| 时段联想加分 | +0.9 |
| 核心主题保底 | 最多 2 条 |
| 兜底补齐 | 补到 4~6 条 |
